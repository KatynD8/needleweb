01
Téléchargement

Récupérez l'installeur

Cliquez sur le bouton Télécharger Plan'Ink Setup ci-dessus. Le fichier Plan-Ink-Setup.exe est téléchargé depuis GitHub Releases (notre hébergement officiel).

02
Installation

Lancez le fichier .exe

Double-cliquez sur Plan-Ink-Setup.exe. L'installation prend environ 30 secondes. Aucune configuration n'est requise.

Windows peut afficher un avertissement "Windows a protégé votre PC". Cliquez sur "Informations complémentaires" puis "Exécuter quand même".

03
Activation

Saisissez votre clé de licence

Au premier lancement, l'écran d'activation apparaît. Collez votre clé de licence (reçue par email après l'achat) puis cliquez sur Activer.

Pas encore de clé ? Vous pouvez en obtenir une sur la page tarifs. À partir de 19€/mois, sans engagement.

§ Questions fréquentes
Pourquoi GitHub Releases pour le téléchargement ? +

GitHub Releases est notre hébergement officiel pour les fichiers d'installation. C'est rapide, fiable, et l'URL /latest/ pointe toujours vers la version la plus récente. Vous pouvez télécharger en toute confiance.

Y a-t-il une version macOS ou Linux ? +

Pas pour le moment. Plan'Ink est actuellement disponible uniquement sur Windows 10 et 11. Les versions macOS et Linux sont prévues dans une mise à jour majeure à venir.

Est-ce que je peux tester Plan'Ink avant d'acheter ? +

L'installeur est librement téléchargeable, mais l'application nécessite une clé de licence pour fonctionner. La meilleure façon de "tester" est de souscrire au plan mensuel à 19€, sans engagement. Si Plan'Ink ne vous convient pas, vous résiliez en un clic, à n'importe quel moment.

Comment se passent les mises à jour ? +

Plan'Ink intègre un système de mises à jour automatiques. Quand une nouvelle version est disponible, elle se télécharge en arrière-plan et s'installe au prochain redémarrage de l'application. Aucune action de votre part n'est nécessaire.

L'application fonctionne-t-elle vraiment hors-ligne ? +

Oui. Toutes vos données (clients, RDV, contrats, finances) sont stockées localement sur votre ordinateur, chiffrées et sauvegardées automatiquement. Seule la vérification de licence requiert une connexion (une fois toutes les 24h, avec une tolérance de 7 jours en cas de problème réseau).
